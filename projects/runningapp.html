Accessible Running Application

A React Native running application designed to provide real-time pace feedback while reducing reliance on visual interaction.

Technologies: React Native, Expo, GPS, AsyncStorage

Overview

The Accessible Running Application is a mobile running app designed to help users maintain their target pace and navigate their run without constantly relying on their phone's screen. The application provides real-time audio feedback based on the runner's pace, with haptic feedback explored as an additional form of feedback. Users can also configure their running preferences and save previous runs for later review.

The Problem

I discovered current running appliaactions mainly focused on the visual aspect of a running application. I reasoned that when you are running it is inconvenient and distracting to keep glacing at your phone so i set out to find away to keep track of your runn whilst running.

Research & Problem Discovery
