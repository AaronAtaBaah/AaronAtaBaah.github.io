Accessible Running Application

A React Native running application designed to provide real-time pace feedback while reducing reliance on visual interaction.

Technologies: React Native, Expo, GPS, AsyncStorage

Overview

The Accessible Running Application is a mobile running app designed to help users maintain their target pace and navigate their run without constantly relying on their phone's screen. The application provides real-time audio feedback based on the runner's pace, with haptic feedback explored as an additional form of feedback. Users can also configure their running preferences and save previous runs for later review.

The Problem

I discovered that current running applications mainly focused on the visual aspect of a running application. I reasoned that when you are running, it can be inconvenient and distracting to keep glancing at your phone. I therefore set out to explore whether a running application could provide useful information while reducing the need to interact with the screen.

Research & Problem Discovery

Design

Design Goals

The design of the application was informed by two main sources: user research and usability evaluation using Nielsen's 10 usability heuristics.

Before development, I collected feedback from runners and general users to understand their experiences with existing fitness applications and identify the features they wanted from a running application. I focused particularly on how users interacted with fitness applications while running, the usefulness of audio feedback, and accessibility.

This feedback was combined with Nielsen's 10 usability heuristics to guide the design and refinement of the interface.

Core Design Goals

Reduce Screen Dependence

Minimise the amount of visual interaction required while running by communicating important information through audio feedback.

Customisable Feedback

Give users greater control over the type and frequency of feedback they receive during a run.

Simple Interface

Keep the interface clear and easy to understand, particularly when users are interacting with the application while running.

Real-Time Feedback

Provide pace information quickly enough for the runner to make adjustments during their run.

User Control

Allow runners to configure their running goals and feedback preferences rather than relying on a fixed feedback system.

Initial Prototype

These design goals provided the foundation for my initial Figma prototype. I used the prototype to establish the application's navigation, screen structure and core running workflow before beginning development.

The initial design focused on keeping the interface simple and reducing the amount of information presented to the runner at one time.

Design Evaluation

The initial prototype was evaluated using feedback from users alongside Nielsen's 10 usability heuristics.

User Feedback

Feedback from users helped identify preferences around accessibility, audio feedback, customisation and the simplicity of the interface.

Usability Heuristics

Nielsen's usability heuristics provided a structured way to identify potential usability issues within the interface.

Design Evolution

The findings from user feedback and heuristic evaluation informed the next stage of the design. The interface was refined before being implemented further in React Native.
